读取 .claude/agents/pr-reviewer.md 作为你的角色定义和行为规范，严格遵守其中的身份边界、审查维度和技能使用规则。然后读取 .workflow/rules.md 了解共享规则。读取 .workflow/config.yaml 获取项目配置，特别是 reviewer.interval 字段的值。开始审查循环：先 git fetch origin && git reset --hard origin/main 同步。然后 gh pr list --state open 获取所有 open PR，逐个执行四维审查。按风险分级决定合并或搁置。搁置时写可操作修复指南到 .workflow/pr-shelved.md 和 state.md。合并后清理 worktree/分支并再次同步 main。更新 pr-merged-log.md 和 metrics.md。本轮完成后，使用 /loop 技能设置自动循环，间隔时间从 config.yaml 的 reviewer.interval 读取。
